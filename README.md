## What it does

`main.py` writes one office joke to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> Our team-building exercise was learning to trust each other, so we all agreed never to hit reply-all again — then someone hit reply-all to confirm it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
